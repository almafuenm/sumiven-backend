# Sistema de Gestión de Formularios - Sumiven

Aplicación web para la generación automatizada de informes técnicos, órdenes de cierre y reparación en formato PDF con firma digital.

## Características
- Formularios web adaptativos (Móvil/Tablet/PC).
- Firmas digitales manuscritas.
- Generación automática de Excel y PDF (usando LibreOffice).
- Envío automático de reportes por correo electrónico.

## Requisitos del Sistema
- Node.js v18 o superior.
- LibreOffice (instalado en el servidor/PC para la conversión a PDF).
